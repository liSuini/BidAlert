# ADR-0003: 工作日计算仅排除周末，暂不支持法定节假日

## 状态
已接受

## 日期
2026-09-27

## 背景
预警计算引擎需要计算两个日期之间的工作日天数。精确的工作日计算需要排除法定节假日（如春节、国庆等），并考虑调休补班（周末上班）。

## 决策
初期工作日计算仅排除周六和周日，不处理法定节假日和调休补班。后续可通过节假日配置表扩展。

## 理由
- **实现简单**：仅需判断 weekday()，无需维护节假日数据
- **节假日数据维护成本高**：每年法定节假日不同，需要人工维护或接入第三方 API
- **误差可接受**：大多数阶段时效为 1-7 个工作日，节假日影响的误差在可接受范围
- **可扩展**：预留 HolidayCalendar 接口，后续实现时只需替换工作日计算函数

## 后果
- 优点：实现快速，无外部依赖，无需维护节假日数据
- 缺点：法定节假日期间计算的工作日偏少（实际休息日更多），可能导致预警/超期判定偏宽松
- 扩展路径：新增 HolidayCalendar 表 + 工作日计算函数加入节假日检查
