## 详细拆分

### M1: 数据库与数据模型（P0）

**描述：** 建立 SQLite 数据库，创建 Project、StageConfig、ImportLog 三张表，预设阶段配置。

**子任务：**
1. 项目初始化：FastAPI 项目骨架 + 依赖安装
2. SQLAlchemy 模型定义（Project、StageConfig、ImportLog）
3. 数据库初始化脚本 + 预设阶段配置数据
4. 投标主体为"信产"时自动填充 ict_digital_date = "不涉及" 的逻辑

**依赖：** 无
**验收标准：** 数据库可初始化，三张表创建成功，预设配置可查询

---

### M2: 预警计算引擎（P0）

**描述：** 实现工作日计算、阶段时效检查、总时长检查，输出项目状态。

**子任务：**
1. 工作日计算工具（排除周末）
2. 阶段时效检查（按金额分界，逐阶段判定）
3. 总时长检查（14/21 工作日）
4. 状态综合判定（normal/warning/overdue/completed + overdue_type + overdue_stage）
5. ICT 立项结束字段动态选择逻辑
6. 单元测试覆盖各状态场景

**依赖：** M1
**验收标准：** 给定项目数据，能正确计算状态、已用天数、剩余天数

---

### M3: 项目 CRUD API（P0）

**描述：** 提供项目的增删改查 REST API，列表接口返回计算字段。

**子任务：**
1. GET /api/projects（筛选 + 分页 + 计算字段）
2. GET /api/projects/{id}（详情 + 计算字段）
3. POST /api/projects（新增，含"不涉及"自动填充）
4. PUT /api/projects/{id}（更新，触发状态重算）
5. DELETE /api/projects/{id}
6. PUT /api/projects/{id}/remark（单独更新情况说明）
7. API 测试

**依赖：** M1, M2
**验收标准：** 所有接口可正常调用，返回正确数据

---

### M4: 统计 API（P0）

**描述：** 提供大屏统计数据接口。

**子任务：**
1. GET /api/stats/overview（各状态计数）
2. GET /api/stats/stages（各阶段分布）
3. GET /api/stats/regions（各地市分布）
4. GET /api/stats/overdue（超期 TOP 列表）

**依赖：** M1, M2
**验收标准：** 返回数据正确，支撑大屏展示

---

### M5: Excel 导入（P0）

**描述：** 上传 Excel 文件，解析并导入项目数据。

**子任务：**
1. 文件上传接口
2. openpyxl 读取 + 字段映射
3. 数据校验（必填、格式、金额）
4. 重复检测（按项目名称）
5. 批量写入 + 失败行跳过
6. 导入模板下载
7. 导入日志记录

**依赖：** M1
**验收标准：** 能导入现有 Excel 清单，返回成功/失败统计

---

### M6: Excel 导出（P1）

**描述：** 按字段勾选导出项目数据为 Excel。

**子任务：**
1. 导出接口（指定字段 + 筛选条件）
2. openpyxl 写入 + 表头
3. 日期格式化 + 状态中文标签
4. 全部导出 / 筛选结果导出

**依赖：** M1, M3
**验收标准：** 导出文件可在 Excel 正常打开

---

### M7: 前端框架搭建（P0）

**描述：** 搭建 Vue3 + Vite + Element Plus + ECharts + Pinia 项目骨架。

**子任务：**

2. 路由配置（4 个视图页面）
3. API 调用封装（axios）
4. Pinia store 定义
5. 顶部导航栏 + 视图切换标签
6. 深色主题基础样式

**依赖：** 无
**验收标准：** 前端可启动，4 个空页面可切换

## 开发顺序建议

```
第一批（P0 核心）：M1 → M2 → M3 → M7 → M8 → M9 → M10 → M12
第二批（P0 补充）：M4 → M5
第三批（P1 增强）：M6 → M11
```

实际建议按以下顺序并行推进：

1. M1（后端数据模型）+ M7（前端框架）并行
2. M2（预警引擎）
3. M3（CRUD API）+ M4（统计 API）
4. M5（Excel 导入）
5. M8（总览大屏）+ M9（看板视图）+ M10（列表视图）+ M12（详情弹窗）
6. M6（Excel 导出）+ M11（管理视图）
